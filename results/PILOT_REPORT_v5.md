# Pilot v5 · 干扰项语义泄漏修复验证

> n=80（四类各 20），6 选项，comp 用 6 次循环置换去偏。
> 本轮只改 mem-L2 的干扰项，题干与 comp 不变。

## 修了什么

### 缺陷 1：典故成语（AID）—— 数据集内循环干扰
`build_mem_options` 拿同类别其他条目的答案当干扰项，二者**语义场完全不同**：

```
Q: 写出成语：出自《左传·庄公六年》，比喻后悔已迟。
gold: 噬脐何及
干扰（修复前）: 蹊田夺牛 / 及瓜而代 / 臣一主二 / 薏苡明珠 / 室如悬罄   ← 全不搭
```

模型读懂释义即可排除全部 5 个，无需记住词形 → L2 测的是语义匹配，不是形式记忆。
**判据：GapB 为负**（L2 比 comp 还简单）。

修复：每条人工配 5 个**同语义场但非该典故形式**的成语。
```
干扰（修复后）: 追悔莫及 / 悔之晚矣 / 后悔无及 / 嗟悔无及 / 悔不当初
```

### 缺陷 2：谐音隐语（YY）—— 答案类型混排
YY 答案跨 5 种类型（单字 / 人名 / 地名 / 成语 / 物名），干扰项却混合各类型：
```
Q: 童谣"千里草，何青青；十日卜，不得生"暗指哪个人物？  gold: 董卓
干扰（修复前）: 绝妙好辞 / 门 / 贾岛 / 鲜 / 大雁   ← 只有董卓是人物
```
类型排除法白送分。修复：字谜配字、人名谜配人名、地名谜配真实湖北地名、成语谜配成语。

> 注：v4 判断的「AID mem 题引文提示过度」确实存在并已修（删除 20 条原文引文），
> 但**删引文后 L2 仍 100%** —— 真正的泄漏在干扰项，不在题干。

### 附带修复
`pilot_aid.md` 两处编码损坏：`神采自??`→`神采自见`（AID-010）、`谢家诸??`→`谢家诸子`（AID-013）。

## 结论被改写

- v4 结论：GapA(55) >> GapB(26)，主缺口在 recall/recognition 的形式差。
- v5 结论：**GapB(55.0) > GapA(31.2)** —— 泄漏的 L2 掩盖了真实缺口。
  真正的缺口是**同尺度下"记得住词形" vs "懂得含义"**的差（55 点），不是任务形式差（31 点）。
- mem_only 象限在两模型上均有样本（Qwen 4、Llama 8），2×2 具备诊断力。

## L1 首字提示梯度（本轮新增）

为把 mem 从 L0(自由回忆) / L2(N选一) 两端补成连续梯度，新增 **L1 = 首字提示补全**：
题干给出首字 + 字数，模型仍需补全其余部分。单字答案（如 YY 的「门」）L1 即全貌，
作为该条下限基线。

**梯度 L0 → L1 → L2 → comp：**
- Qwen ALL：6.2% → 20.0% → 37.5% → 92.5%（单调上升）
- Llama ALL：0% → 8.8% → 22.5% → 50%（单调上升）

**方法论坑（必须标注）：L1 的信息量随答案长度变化，跨类不可直接比。**
- 歇后语/农谚是长短语（出力不讨好 / 上来就得没锅台），给首字几乎无用 → L1 仍 0%。
- 谐音双关答案是短词（门 / 董卓 / 绝妙好辞），给首字约束极强 → L1 飙到 30–55%。
  Qwen 上 phonetic_play 出现 **L1(55%) > L2(35%)**：首字提示比 6 个近义选项更易补全，
  是答案长度所致，非矛盾。
- 结论：L1 对**等长子答案**（如四字成语 allusion_idiom：L0 5 → L1 25 → L2 35）是干净的梯度步；
  跨长度类别比较时需归一化（建议 L1 改为"揭示首 50% 字符"而非仅首字）。
