# AID 受控探针实验：100% 是真实理解还是干扰项太弱？

> 触发：用户质疑 v8 报告中「AID 高 comp = 真实理解」缺证据，指出旧干扰项是
> 「常见、语义各异的成语」而非「同语义场、不同典故」的近邻，模型靠**常识排除**
> 而非理解选对。要求挑 5 条 AID 改造成真近邻干扰项、重跑 qwen-max 验证。



##  实验设计
挑 5 条语义场丰富的 AID，逐条手工撰写**同语义场、不同典故**的硬干扰项
（纯含义表述，不含成语名，避免变成「识名题」），与金标同风格：

| id | 成语 | 语义场 | 干扰项（同场、异典故） |
|----|------|--------|------------------------|
| AID-001 | 噬脐何及 | 后悔/追悔 | 事后追悔却无可挽回 / 懊恼当初错误选择 / 终身抱恨 / 错失良机深悔 / 悔恨萦绕 |
| AID-002 | 室如悬罄 | 贫穷 | 家徒四壁 / 一贫如洗 / 环堵萧然 / 囊空如洗 / 瓮牖绳枢 |
| AID-005 | 薏苡明珠 | 蒙冤受谗 | 不白之冤 / 含冤负屈 / 谗口铄金 / 众口铄金 / 明珠投暗 |
| AID-013 | 封胡羯末 | 佳子弟 | 龙驹凤雏 / 麟子凤雏 / 凤毛麟角 / 千里驹 / 宁馨儿 |
| AID-014 | 翳桑之饿 | 感恩报本 | 结草衔环 / 一饭千金 / 知遇之恩 / 投桃报李 / 羔羊跪乳 |

注：AID-014 正是用户举的反例模板（翳桑之饿 = 知恩图报），按用户设想的同场设计。

方法：只改这 5 条的 comp 干扰项 → rebuild `pilot.jsonl` → 从结果文件删除这 5 个 id
让 `run_pilot.py` 断点续跑只重跑它们（`PERMS=6` 循环置换去偏），与其余 75 条既有结果合并。

## 结果
### 3.1 三模型、探针 5 条（真近邻干扰项）逐条
| id | 语义场 | turbo | plus | max |
|----|--------|-------|------|-----|
| AID-001 | 后悔场 | ✓ | ✓ | ✓ |
| AID-002 | 贫穷场 | ✓ | ✓ | ✓ |
| AID-005 | 蒙冤场 | ✓ | ✓ | ✓ |
| AID-013 | 佳子弟场 | ✓ | ✓ | ✓ |
| AID-014 | 感恩场 | ✓ | ✓ | ✓ |
| **合计** | | **5/5=100%** | **5/5=100%** | **5/5=100%** |

### 3.2 全部 20 条 AID（探针 5 条 + 其余 15 条旧干扰项）
- qwen-plus：**20/20 = 100%**
- qwen-max：**20/20 = 100%**
- qwen-turbo：19/20 = 95%（唯一错的 AID-015 踊贵屦贱，仅 turbo 在 acc=0.17 随机线，非探针项）

## 4. 一个必须坦白的方法论教训
第一次跑 AID-013 时，我把干扰项写成 **3 个谢家典故**（封胡羯末本身 + 谢庭兰玉 +
芝兰玉树），过度聚簇。结果 qwen-max 在 AID-013 上从 100% 暴跌到 **17%（≈随机 1/6）**，
一度看似「虚高被戳穿」。但这是**探针设计缺陷**——同家族近义项互相不可分，对人亦然。
修正为「同场但不同典故、无谢家重叠」的干扰项（龙驹凤雏/麟子凤雏/凤毛麟角/千里驹/
宁馨儿）后，AID-013 三模型全部回到 100%。

> 教训：**「近邻干扰项」必须同语义场 + 不同典故来源**，绝不能在同一个典故家族里找
> 近义变体，否则测出来的不是理解力，是干扰项之间的不可分性。这条应写进论文的
> 命题协议（distractor 构造规范）。

## 5. 结论
- 按用户自己的判据「仍 100% → 真懂」：**证据支持 AID 高 comp 是真实理解**。
  即便换成同语义场近邻干扰项，5 条探针在三模型上仍全对；全部 20 条在 plus/max 上全对。
- 因此 **v8 报告「AID 高 comp = 真实理解」成立**，用户的「旧 100% 是干扰项太弱造成的虚高」
  预测**未被本探针证实**（comp 没降到 60–80%）。
- 但用户的**方法论批评方向完全正确**：旧 v8 的 AID 干扰项确实是「常识排除型」弱项，
  只是模型恰好真懂这些典故，所以弱干扰项没「制造」虚高、只是「没暴露」少数盲区
  （如 turbo 在 AID-015 的随机级失误）。

## 6. 对全数据集含意的修正
真正的 M-C 分离缺口在 **xiehouyu / phonetic_play / agrarian_proverb**（v8 去题干泄露 +
硬干扰后 comp 降到 70–85%、mem_only>0 出现），**不在 allusion_idiom**。
论文故事应写为：模型对典故成语覆盖扎实，而对乡土歇后语/字谜/农谚的形式记忆与理解
双重薄弱——后三类才是长尾修辞理解评测的 discriminating 维度。
