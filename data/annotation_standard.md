## 一、冷门度操作标准（exposure / 冷门度）

冷门度是**可测量**的，不是"我觉得偏"。每条目必须给出三路证据后定档：

| 档位 | 搜索引擎 exact-match 结果数 | n-gram 语料命中 (CCL/人民日报/BNC-zh) | 独立模型先验命中率 (≥2 个不同源模型 zero-shot 能答出) | 处置 |
|---|---|---|---|---|
| ★★★（核心长尾） | < 50 | ≈ 0 | < 10% | 录用 |
| ★★（较冷） | 50 – 500 | 少量 | 10% – 30% | 录用（作 mid-exposure 对照） |
| ★（常见长尾） | 500 – 2000 | 可查到 | 30% – 50% | 录用但须标 `exposure_bin=high` |
| 剔除线 | > 2000 或 先验 > 50% | 高频 | > 50% | **剔除**，或仅作 high-exposure anchor（不计入长尾主集） |

### 1.1 测量法（3-source）
1. **搜索引擎 exact-match**：用条目完整上句 / 完整成语 / 完整谜面作精确短语检索，数返回条数（去聚合、去聚合页）。
2. **n-gram 语料**：在 CCL 语料库 / 人民日报语料 / BNC 中文子库检索完整片段，记录命中频次。
3. **独立模型先验**：见 §1.3。

### 1.2 `corpus_coverage` 字段（新增，解决 n-gram 对方言覆盖极低问题）
- 取值 ∈ {`covered`, `partial`, `not_covered`}。
  - `covered`：CCL/人民日报/BNC-zh 中能稳定命中该片段（如经典成语、常见古诗文）。
  - `partial`：仅部分子串命中或频次极低。
  - `not_covered`：n-gram 语料完全无覆盖（典型为方言歇后语、方言多义词、县域农谚）。
- **规则**：`corpus_coverage = not_covered` 时，n-gram 列**必须填 `NA`**，冷门度判定改由「搜索 exact-match + 独立模型先验 + 人工判定」三源合并，不得留空或伪造 n-gram 数。
- 类1/类2-A/类4（农谚）绝大多数属 `not_covered`，以搜索 + 模型先验 + 母语者确认为准。
- **`corpus_coverage` 判定标准（量化阈值）**：
  - `covered`：该方言/地区在 CCL、人民日报、BNC-zh **任一**语料中有 **≥100 条**同方言/同地区文本（判定用「地区关键词 + 方言关键词」双查，如「永登」+「甘肃方言」）。
  - `partial`：同上有 **10–100 条**。
  - `not_covered`：**< 10 条或完全没有**。
  - **无法判定时默认 `not_covered`**，n-gram 列填 `NA`。
- **论文 limitations 明示**：n-gram 语料对方言/县域覆盖不足，曝光审计以「搜索 + 独立模型先验 + 人工」多源综合为准，n-gram 仅作辅助。

### 1.3 独立模型先验具体化（新增，避免与主评估 Qwen 系列循环）
- **必须用训练源不同的模型**，不得用主评估模型（避免循环论证）。采用 **三源**（三个不同机构、不同训练数据）：
  - **Llama-3.1-8B-Instruct**（Meta，国际开源）
  - **Qwen2.5-7B-Instruct**（阿里，中文开源）
  - **GLM-4-9B**（智谱，中文开源，第三机构源）
  - *可选闭源替代*：若环境有 API，可将第三源换为 **GPT-4o-mini** 或 **Claude Haiku**（国际闭源），构成「国际开源 + 中文开源 + 国际闭源」三源。
- **记录项（每条审计必须写）**：模型版本 / 权重来源或 API 快照日期 / 调用日期 / 温度（建议 0.7）/ 采样数（≥5 次取命中率）/ prompt 模板原文。
- **三源一致性报告**：计算三源命中率的 Spearman 相关；若一致性低（如某源明显偏离），在 limitations 说明「先验指标可能不稳定」，并复测或剔除该源。
- 判定：≥2 个不同源模型在 ≥5 次采样中 zero-shot 答对比例 < 10% → ★★★；10%–30% → ★★；30%–50% → ★ 且标 `exposure_bin=high`；>50% → 剔除线。

> 注：v2 稿里所有 `exposure` 字段标了 `TBD`，是因为彼时按"先不跑"未实测。进入本文件流程后，**候选阶段就要跑 3-source 审计**，不能再拖到生成阶段。

## 二、来源质量分级（A / B / C）

每条目必须标一个来源等级，且**最终出处不能是 C**。

- **A 级（原典 / 权威）**：经史子集原典、地方志（县志/府志/省方志办）、方言志、学术专著、权威辞典（《汉语大词典》《辞源》书证）、CSSCI 论文。→ 可作最终出处。
- **B 级（正规机构）**：政府文化页（文旅厅/县政府官网）、正规媒体（新华社、光明日报、地方党报）、学术机构发布页。→ 可作最终出处。
- **C 级（UGC / 自媒体）**：百科（百度/搜狗/360）、今日头条、美篇、网易号、搜狐号、自媒体整理。→ **仅作线索，不得作为最终出处**；凡当前以 C 级为"来源"的条目，必须回原典/方志/权威辞典补 A/B 级出处，否则降级或剔除。
- **`C*` 标记**：候选池中临时以 C 级为线索、待回 A/B 补证者，统一标 `C*`。补证前**不得计入已验收的 A/B 出处条数**（§十三 门槛 1 的硬性约束）。

## 三、mem_task / comp_task 配对规范

**硬性规则：每条 item 必须同时拥有配对的 mem_task + comp_task。** 不允许只有一类。

### 3.1 mem_task（文化记忆 / 固定形式补全）— 考察"知识是否缺失"
- 类1 歇后语：`上句 → 补全下句`（固定形式）。
- 类2-A 歧义：给出含歧义词的方言小句，补全/选出该词在此语境下的**正确义项**。
- 类2-B 谐音：给出表面文本，写出隐藏义 / 谐音对。
- 类3 典故成语：给出典故出处片段，补全成语原词 / 写出今义。
- 类4 农谚：上句 → 补全下句，或其隐喻所指。

### 3.2 comp_task（文化理解 / 多选）— 考察"拿到知识后能否推理理解修辞义"，4 选 1
- distractor 必须覆盖以下 **四类各至少一种**（保证诊断力）：
  1. **字面义**（取表面/非修辞读法的干扰）；
  2. **高频义**（该词/句在现代汉语的常见义干扰）；
  3. **文化错位**（张冠李戴，把 A 地域/典故的含义安到 B）；
  4. **语义合理但民俗错误**（读得通但违背实际民俗/出处）。
- **诊断价值**：mem 错 + comp 错 = 知识缺失；mem 对 + comp 错 = 推理失败。二者解耦才能定位模型短板。

### 3.3 任务 stimuli 硬约束（审稿人防线）
- **类2-A / 类2-B 一律用来源中原句 / 原谜面作 stimuli，禁止自造「说明性例句」**（用户原话：审稿人会一眼看穿）。候选池已写明，生成阶段违规即打回。

## 四、RAG 检索条件设计（定稿）

> 用户拍板：**主实验用旧设计 A/B/C/D**（直接对应"文化图式整合不足"假设）；**新设计（检索命中/未命中/误导）作为 RAG 鲁棒性子实验**，放 Analysis 或附录。两套条件在 prompt 构造层不同，但共用同一 mem/comp 配对与评分。

### 4.1 主实验四条件（文化图式整合假设）
| 条件 | 检索上下文 | 对应假设 | 预期信号 |
|---|---|---|---|
| **A 无知识** | 不提供任何检索上下文 | 基线：模型纯靠参数记忆 | mem/comp 全靠内在知识 |
| **B 只给文化背景** | 给相关文化背景但不给答案 | 有图式提示能否补全缺失知识 | 看背景是否救回 mem 错 |
| **C 给相关但不完全片段** | 给片段但不含关键答案 | 部分信息是否会误导整合 | 部分片段下 comp 是否崩 |
| **D 给完整词典释义（oracle）** | 给完整权威释义 | 知识齐全时能否正确整合推理 | 此时仍错=推理/整合失败 |

- 主实验分析核心：对比 A→D，mem 与 comp 是否**单调提升**；D 下仍 comp 错 = 推理失败（纯知识充分也救不回）→ 支撑"文化图式整合不足"主张。

### 4.2 知识片段来源与操作化（B/C/D 必填字段）
- **B 条件（文化背景）**：片段来自 **A/B 级来源**（地方志、方言志、权威辞典），但**不含目标条目释义句**；`contains_answer=false`。
- **C 条件（相关但不完全片段）——操作化**：给**同类别、不同条目**的文化背景片段（如给另一条农谚的释义，但不给目标条目的答案），**或**给目标条目的百科背景但不含释义句。每个 C 片段必须 `contains_answer=false`，并**抽样（≥20%）人工核查**标记准确性。
- **D 条件（oracle）**：完整词典/原典释义，标 `contains_answer=true`、`oracle=true`。
- **每个片段统一字段**：`source`（A/B 级出处）、`contains_answer`（布尔）、`oracle`（布尔）、`tokens`（片段长度，用于控制上下文长度一致）。
- **一致性核查**：抽样人工核对 `contains_answer` 标记是否准确，错误率 > 5% 重写该批片段。

### 4.3 子实验四条件（RAG 鲁棒性，放 Analysis/附录）
| 条件 | 检索上下文 | 测什么 |
|---|---|---|
| **A 无检索** | 无 | 基线 |
| **B 检索命中** | 检索返回正确片段 | 正确检索是否提升 |
| **C 检索未命中** | 检索返回无关片段 | 检索失败时模型是否自持 |
| **D 检索误导** | 检索返回错误但看似合理片段（人工构造，标 `misleading=true`） | 模型是否盲从误导检索 |

- 子实验单独报告，不与主实验 2×2 四象限混算；仅作鲁棒性补充证据。各条件片段同样带 `contains_answer` / `misleading` 标记。

### 4.4 抽样
- RAG 四条件按 `exposure_bin` 分层抽样；anchor 集（high-exposure）单独跑，不计入长尾主集统计。

## 五、曝光审计流程（候选阶段执行，不拖延到生成）

1. 对候选池**每一条**跑 §一 的 3-source 测量（搜索 + n-gram + 独立模型先验）。
2. 填 `corpus_coverage`（§1.2）；`not_covered` 时 n-gram=NA。
3. 计算 `exposure_index`（可归一化 0–1：命中数 log 缩放 + 先验命中率加权）与 `exposure_bin` ∈ {low, mid, high}。
4. 结果回填 `candidates.md` 的 `exposure` 列（替换 TBD）。
5. `exposure_bin=high` 的条目：剔除，或移至 high-exposure anchor 集（不进长尾主集）。
6. RAG 实验四条件在生成 response 阶段按 `exposure_bin` 分层抽样（见 §四）。

## 六、类2 真实句验证流程（方言多义词歧义硬门槛）

> 针对类2-A（方言多义词歧义）。用户要求：每个方言多义词须回 A/B 源找含该词真实句子，2 名方言母语者确认"本地真能这么说"，否则不进主集。

流程（每条类2-A 必做）：
1. **回 A/B 源取证**：从方言志 / 县政府页 / 学术语料中找出**含该歧义词的真实方言小句**（非自造）。例：桐乡「精（猪头肉三分精）」须有桐乡语料原句；纳雍「谷子/茶叶」须有纳雍政府页原句。
2. **母语者确认**：≥2 名该方言母语者独立确认"这句话本地真能这么说 / 这个词本地确有此义"，记录确认人、地区、日期。
3. **判定**：
   - 有 A/B 真实句 + ≥2 母语者确认 → 进主集，标 `native_speaker_verified=true`。
   - 仅有 C 线索或无真实句 → 标 `C*` 或 `unverified`，**不进主集**，留储备候补。
4. 验证记录随条目归档（来源句 + 确认人 + 日期），进数据卡（§十）。

## 八、人类验证协议（新增）

目的：用人类一致性证明"长尾修辞判断"有客观标准，非主观。

- **分层抽样**：北方 / 非北方 / 民俗专家 三层；每层覆盖 4 类与三类机制（歧义/谐音/典故/农谚隐喻）。
- **实验设计**：拉丁方（Latin Square）平衡 item×标注者顺序效应。
- **人数**：每 item ≥ 3 人评（含 ≥2 名北方民俗母语者）。
- **样本量论证（为何 ≥3 人）**：
  - 每 item 至少 **3 人**评，用于算 item 级评分者间一致性；预算允许时 **5 人**更稳。
  - 标注者规模：**北方民俗母语者每类 5–10 人**，**非北方 5–10 人**，**民俗专家 1–2 人**。
  - 用**拉丁方设计**，每人只做全部 item 的一个子集，总覆盖全部 item，降低单人疲劳偏差。
  - 报告每个 item 的评分人数、评分者间一致性、争议类型。
  - 若某 item 仅 1–2 人评，标 `low_coverage`，在分析中**降权或剔除**。
- **指标**：Cohen's κ（双人）或 Fleiss' κ（多人），**κ > 0.7** 为达标线；0.6–0.7 重训后复测；<0.6 该 item 重写或剔除。
- **人口学报告**：标注者地区/方言/年龄/教育背景随数据卡发布（§十），供审稿人审"标注者代表性"。
- **与门槛关系**：见 §十三 门槛 4。

## 九、数据划分策略（新增）

- **同源不跨 dev/test**：同一来源句 / 同一原典 / 同一县志 派生条目不跨 dev 与 test，防泄漏。
- **配对同 split**：一条 item 的 mem_task 与 comp_task 必须同 split（同进 dev / 同进 test）。
- **分层抽样**：按 类 × 机制（歧义/谐音/典故/农谚）× 曝光度（low/mid/high）分层切分，保证各 split 分布一致。
- **anchor 独立**：high-exposure anchor 集、weather-only 子集单独成集，不参与长尾主集 train/dev/test 统计，仅作对照。
- **anchor 子集具体划分（均不进长尾主集，独立报告）**：
  - `high_exposure_anchor`：高曝光条目，对照「高曝光上模型表现如何」。
  - `mid_exposure_anchor`：mid 曝光条目（如曹娥碑、千里草），对照。
  - `weather_only_anchor`：纯气象农谚（类5 剔除项），对照。
  - `life_philosophy_anchor`：人生哲理谚语（类5 移出项，如「隔手的金子不如到手的铜」），对照。
  - 所有 anchor 集**不跨 dev/test**，独立成集、独立报告。

## 十一、标注手册与争议类型（新增）

- **标注手册**：独立文档（后续写），规定每条冷门度/来源/distractor 的标注步骤、示例、边界。
- **争议类型（标注中高频分歧，手册须覆盖）**：
  1. 冷门度档位临界（★★ vs ★★ 边界，如搜索 480 vs 520）。
  2. 来源等级临界（B 媒体 vs C 自媒体，如"地方党报客户端" vs "搜狐号"）。
  3. distractor 是否真"语义合理但民俗错误"（易与字面义混淆）。
  4. 方言多义词"本地真能这么说"母语者分歧（§六）。
  5. 类3 classic_cold vs local_gazetteer 归类的长尾性争议。
  6. 类5 life_philosophy 是否算 agrarian-context。
- **争议类型枚举（标注须逐类记录数量/案例/仲裁结果，可进 Analysis）**：
  - `category_disagreement`：类别归属分歧（如某条该归类1还是类2）。
  - `meaning_disagreement`：释义分歧。
  - `metaphor_type_disagreement`：`metaphor_type` 判定分歧（agrarian_metaphor / pure_weather / life_philosophy）。
  - `exposure_disagreement`：曝光度三源分歧（搜索/n-gram/模型先验不一致）。
  - `distractor_type_disagreement`：distractor 类型判定分歧（四类覆盖是否齐全）。
  - `boundary_case`：边界项，如 尿泡打人 是否算歇后语。
  - `source_quality_disagreement`：来源等级判定分歧（A/B/C 临界）。
- 每类争议记录：数量、典型案例、仲裁结果；≥2 专家仲裁，记录进 CHANGELOG（§十二）。
